KidsSongMaker

KidsSongMaker is a private content-creation automation tool operated by its developer.

The software creates original educational children's videos and uses the YouTube Data API to upload videos, titles, descriptions, tags, and thumbnails to the developer's own authorized YouTube channel.

KidsSongMaker is not offered as a public YouTube account management service and does not provide third-party users with access to YouTube accounts or YouTube user data.

YouTube API Usage

YouTube authorization is performed using Google OAuth 2.0. The application requests only the permissions required for video upload.
