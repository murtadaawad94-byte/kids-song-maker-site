KidsSongMaker Privacy Policy

KidsSongMaker is a privately operated content-creation tool used by its developer to create and upload videos to the developer's own authorized YouTube channel.

Use of YouTube API Services

KidsSongMaker uses YouTube API Services and Google OAuth 2.0. The application uses authorization granted by the account owner solely for uploading videos and associated metadata such as titles, descriptions, tags, and thumbnails.

By using YouTube API Services, users are also subject to the Google Privacy Policy: Google Privacy Policy

Information Accessed and Stored

KidsSongMaker stores OAuth authorization credentials required to access the authorized YouTube account. These credentials are used only to perform the functions authorized by the account owner.

KidsSongMaker does not sell Google user data, use Google user data for advertising, or provide Google account data to third parties.

Data Retention and Deletion

Authentication credentials are retained only while authorization is required for the automated uploader.

The account owner may request deletion of locally stored authorization credentials at any time. Revoking Google access also prevents KidsSongMaker from obtaining new access tokens.

Revoking Access

Access granted to KidsSongMaker can be revoked at any time using Google's third-party application permissions page: Google Account third-party connections

Contact

For privacy or data-deletion requests, contact the developer using the contact information supplied with the YouTube API compliance submission.
